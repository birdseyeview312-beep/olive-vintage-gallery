HOW LIVE AUCTIONS WORK

One setup, then one-button broadcasts

  1. Owner connects Cloudflare Realtime here one time.
  2. Open Auction Manager.
  3. Select an auction and press Create Broadcast.
  4. Start streaming from your broadcaster.
  5. The Cloudflare playback URL is attached to the auction page automatically.
Bidding never depends on video timing.

Supabase remains the authority for the bid amount, lot countdown, and anti-sniping extension even if a viewer's video is a few seconds behind.
